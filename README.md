# Ultrasound AI Assistant

**Статус: заготовка репозитория.** Сейчас в проекте нет реализации приложения,
модели, inference, датасета, конфигурации зависимостей или тестов.
Наличие лицензии не означает наличие готового продукта.

## Что требуется для следующего этапа

- определить одну конкретную исследовательскую задачу и ожидаемый вход/выход;
- описать происхождение и допустимость использования данных;
- выбрать baseline и воспроизводимый протокол оценки;
- добавить минимальную реализацию, зависимости, synthetic smoke test и CI;
- документировать ограничения и результаты с проверяемыми артефактами.

Качество, клиническая применимость и готовность к эксплуатации не подтверждены.
Этот репозиторий не содержит работающего инструмента для клинических решений.
